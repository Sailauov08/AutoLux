## Жоба туралы

AutoLux — бұл жай сайт емес, автосалонның бүкіл жұмысын бір жерге жинайтын веб-платформа.

- **Клиент** көліктерді қарап, салыстырады, несиені есептейді, тест-драйвқа жазылады.
- **Менеджерлер** өтінімдерді қабылдап, клиенттермен жұмыс істейді, сатуды тіркейді.
- **Иесі** аналитиканы, команданы және бүкіл салонды басқарады.

Сайт үш тілде жұмыс істейді (қазақ, орыс, ағылшын), дизайны "Midnight Edition" деп аталады: қараңғы және жарық тақырып, премиум типографика, жұмсақ анимациялар.

> *English:* AutoLux is a full-stack dealership platform: a premium trilingual storefront plus a role-based CRM and admin dashboard, built with Next.js 16 and Supabase (Postgres, Auth, Storage, Row Level Security).

## 🔒 Қауіпсіздік

Қауіпсіздік интерфейсте ғана емес, **дерекқор деңгейінде** қамтамасыз етілген:

- **Row Level Security** барлық кестеде қосулы: пайдаланушы тек өзіне рұқсат етілген жолдарды көреді.
- **Салондарды бөлу:** composite foreign key арқылы бір салонның деректері екінші салонға ешқашан араласпайды.
- **Маңызды әрекеттер** (сату, баға бекіту, рөл беру) тек тексерілген `SECURITY DEFINER` функциялары арқылы орындалады.
- **Optimistic locking:** `version` бағаны екі адам бір жазбаны бір уақытта өзгертіп, бірінің өзгерісі жоғалып кетуінен қорғайды.
- **Құпия кілттер:** қолданба тек public (publishable) кілтті пайдаланады. Service-role кілті табылса, қолданба іске қосылмайды.
- **Build тексеруі:** арнайы тест клиентке жіберілетін JavaScript ішінде құпия кілт жоқ екенін тексереді.
- **Валидация:** барлық форма серверде Zod арқылы тексеріледі.

## ⚡ Жылдамдық

- Каталог пен салон туралы ақпарат серверде кэштеледі. Админ өзгеріс енгізгенде кэш бірден жаңарады.
- Сессия JWT арқылы жергілікті тексеріледі, әр бетте Auth серверіне артық сұрау жіберілмейді.
- Бет ауысқанда бірден жүктелу индикаторы көрсетіледі.
- Көлік беттері алдын ала статикалық түрде құрастырылады (SSG + ISR).

## 🚀 Жергілікті іске қосу

```bash
git clone https://github.com/Sailauov08/AutoLux.git
cd AutoLux
npm install
cp .env.example .env.local   # Supabase URL мен publishable кілтті енгізіңіз
npm run dev
```

Сайт http://localhost:3000 адресінде ашылады. Supabase қосылмаса, сайт демо режимде үлгі көліктермен жұмыс істейді.

Дерекқорды баптау: [docs/SUPABASE_SETUP.md](docs/SUPABASE_SETUP.md). `npm run db:bundle` командасы барлық миграция мен seed-ті бір `supabase/setup.sql` файлына жинайды.

### Айнымалылар

| Айнымалы | Сипаттамасы |
|---|---|
| `NEXT_PUBLIC_SUPABASE_URL` | Supabase жобасының URL |
| `NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY` | Publishable кілт (құпия емес) |
| `NEXT_PUBLIC_DEALERSHIP_SLUG` | `autolux` |
| `NEXT_PUBLIC_SITE_URL` | Сайттың ашық адресі (email сілтемелері үшін) |

### Командалар

| Команда | Не істейді |
|---|---|
| `npm run dev` | Әзірлеу серверін іске қосады |
| `npm run build` / `npm start` | Production build жасап, іске қосады |
| `npm run typecheck` | TypeScript тексеруі |
| `npm run lint` | ESLint |
| `npm test` | Барлық тест (unit + дерекқор + қауіпсіздік) |
| `npm run db:bundle` | `supabase/setup.sql` файлын жинайды |

## ✅ Тесттер

63 тест, оның ішінде:

- **Дерекқор тесттері:** нақты Postgres (PGlite) ішінде миграциялар, RLS саясаттары және рөлдер тексеріледі.
- **Қауіпсіздік тесттері:**
  - бір салон екінші салонның деректерін көре алмайтыны;
  - клиент персонал функцияларын шақыра алмайтыны;
  - ішкі функциялар сырттан ашық емес екені.
- **Аударма тесттері:** үш тілдегі кілттердің толық сәйкес келетіні.
- **Build тесті:** клиентке жіберілетін JavaScript ішінде құпия кілттің жоқтығы.
